# Victor Digital Double

A standalone public landing page introducing Victor Chucks Jim's Cognitive Twin concept.

## Live site
Once GitHub Pages is enabled and the deployment workflow succeeds:
https://victorchucksjim.github.io/Digital-double-/

## Deploy
This repository uses GitHub Actions to publish the static site to GitHub Pages. In **Settings → Pages**, set **Build and deployment → Source** to **GitHub Actions**.

The page is plain HTML, CSS and JavaScript. It has no build step and no dependency on the Victor Chucks Jim portfolio website or AWS hosting.
